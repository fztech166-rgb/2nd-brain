    “System” plan-এ আপনার নিজের API key ব্যবহার হয় (usage limit থাকে)। “Full” plan-এ system-এর global provider ব্যবহার হয় — এতে API key দেওয়ার কোনো অপশন থাকে না।

    এই ডিভাইসে ২টার বেশি একাউন্ট তৈরি হয়েছে — তাই ফ্রি AI credits দেওয়া বন্ধ করা হয়েছে।

    Platform package — নিজের AI key setup guide

    আপনি Platform package-এ আছেন — সব feature আনলক, কিন্তু AI চালাতে আপনার নিজের API key লাগবে। নিচের ধাপে ২ মিনিটেই হয়ে যাবে। একটাই key যথেষ্ট (Gemini বা Groq)।

    1. Gemini key: খুলুন aistudio.google.com/apikey → Create API key → নতুন key কপি করুন। (ফ্রি tier-এ প্রচুর request।)
    2. Groq key (alternative): খুলুন console.groq.com/keys → Create API key → কপি করুন। (অতি দ্রুত, সম্পূর্ণ ফ্রি।)
    3. উপরের Your AI Keys কার্ডে key পেস্ট করুন → Save চাপুন।
    4. শেষ! AI Chat, Explain, Mind Map, Question Bank — সব এখন কাজ করবে।

    💡 key বিল করা হয় আপনার Google/Groq account-এ — যত ব্যবহার তত খরচ, তাই প্রতিবার প্রশ্ন করতে ২টা credit কাটা হবে না।
